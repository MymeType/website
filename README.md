# MymeType's website

## Where to access

- [Nekoweb](https://mymetype.nekoweb.org) (more stable)
- [Self-hosted Caddy server](https://caddy.textht.ml) (backup, run on a best-effort basis)

## Development guide

Install dependencies:

`npm install`

Run dev server:

`npm run dev`

Build and upload to Nekoweb (requires your API key in the `NEKOWEB_API_KEY` environment variable):

`npm run build`

## List of software and platforms used
