## Development guide

Install dependencies:

`bun install`

Run dev server:

`bun run dev`

Build and upload to Nekoweb (requires your API key in the `NEKOWEB_API_KEY` environment variable):

`bun run build`

## List of software and platforms used

- [Astro](https://astro.build/)
- [astro-adapter-nekoweb](https://github.com/indiefellas/astro-adapter-nekoweb)
- [dotenv](https://www.npmjs.com/package/dotenv)
- [Nekoweb](https://nekoweb.org/)
- [Stylus](https://stylus-lang.com/)
- [Tangled spindles](https://docs.tangled.org/spindles)
- [TypeScript](https://www.typescriptlang.org)
